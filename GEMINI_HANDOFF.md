## Неизменяемые требования

1. Английские UI, подписи, логи, tooltip. Русский допустим только как вторичные метаданные.
2. Никаких маркетинговых сравнений, fake latency, «дешевле LLM», выдуманных токенов, фиктивных вероятностей и калькуляторов масштаба.
3. Телеметрия только по реальному ответу: backend HTTP roundtrip через монотонные часы; input/output usage; вход $0.042 / 1M токенов, выход бесплатный.
4. Стоимость считается целыми nano-USD: один входной токен = 42 nano-USD. Строка USD — девять знаков после запятой. Нулевая стоимость не должна подменяться fallback через `||`.
5. Cache: новый charge = 0, latencyMs = null, usage = null. Session spend — сумма полученных live-ответов данной страницы; это не гарантированная сверка счёта провайдера. Missing usage явно unknown.
6. На ленте — pixel-art, не плавающие подписи. Детали — в инспекторе/hover. Цвета веток: #38bdf8, #fb923c, #f87171, #4ade80.
7. Не меняй чужие файлы/сервисы, не раскрывай секреты, не перезапускай DSH. Не отключай SSH host-key verification.

## Jev

- Endpoint: `https://api.typesafe.ai/v1/systemone`, модель `jev-latest` (наблюдалась `jev-1.13.0`).
- **Обязательный proxy: `http://192.168.0.142:18080`** через HttpsProxyAgent. Никакого прямого fallback.
- Ключ: `TYPESAFE_API_KEY`, только backend. В локальной среде поддержан существующий DSH credential reference; не выводи его содержимое.
- Typed вопросы: категория choice, hazard noul, rarity score. Типовая корректность не доказывает семантическую правильность.
- Фактически наблюдавшийся полный HTTP roundtrip около 1.2–1.5 секунды. **Не заявляй sub-150ms**, если этого не показало измерение.

## Лимиты API и безлимитный тариф

- По прямому указанию владельца **искусственные локальные ограничения сняты** (убраны лимиты 120 запросов/минуту и ограничение в 6 параллельных вызовов): на нашей стороне API безлимитная.
- Соблюдаются **только реальные ограничения самого upstream API TypeSafe AI**: если `api.typesafe.ai` возвращает HTTP 429, этот статус и сообщение об ожидании корректно передаются клиенту.
- Сохранены базовые защитные меры: валидация входных полей (размер тела до 8 КиБ, имя до 160 символов, описание до 2000 символов), таймаут 10 секунд и in-memory кэш повторных запросов (до 1000 записей).
- Create assets — All Rights Reserved, не MIT как остальной код. Botania — свои условия, wiki assets — индивидуальные права. Публичный доступ не означает полученное разрешение на распространение. Уточняй разрешения/замены с владельцем, не заявляй юридическую чистоту.
- «Osmotic Concentrator» не найден в реестре Mekanism; включён реальный Osmium Compressor с поисковым alias. Не изобретай несуществующий блок.
- Некоторые блоки используют реальную плоскую текстуру, а не 3D inventory render; именованные ключевые машины получили wiki-иконки. Старые wiki-версии явно отражены в provenance.
- Независимого reviewer acceptance не было; выполнены координаторское ревью и реальные тесты.

## Проверки

TEST_URL=https://jev.ninitux.com TEST_OUTPUT_DIR=artifacts/public-deployment node scripts/e2e_verify.js

E2E использует установленный Puppeteer headless-shell; полный Chrome в этом окружении падал из-за crashpad. Тест делает реальные платные вызовы. `pnpm run test:failures` использует локальные fixtures и по умолчанию локальный server:3333. Не называй fixture проверкой реального API.

Последние наблюдения: 15 unit checks, 40 browser checks, около 60 FPS, отсутствие console/page/request errors; весь каталог декодировался. Сверь актуальные JSON-отчёты и повторяй только применимые проверки после изменений. `?diagnostics=1` включает read-only snapshots/frame intervals, не обход Jev.
